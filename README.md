# Portfolio

Static portfolio in a "2001 console chrome" style. Plain HTML/CSS/SVG, generated by a small Python build.

## Build & preview

```bash
pip install -r requirements.txt          # Pillow (reads image sizes)
python build.py                          # writes site/
python -m http.server 8765 -d site       # http://localhost:8765/
```

## Folders

| Folder | What | Published? |
|---|---|---|
| `assets/` | CSS, JS, images (`assets/img/slots/`) | yes (copied to `site/assets/`) |
| `static/` | Files copied as-is: résumés, full-size diagrams, NumIsToken mockups | yes |
| `site/` | Generated output: the only thing to deploy | yes (git-ignored, rebuilt) |
| `_private/` | Repo dumps, design guide, unused images, **restricted CBU figures** | **never** (git-ignored) |

Edit copy in `pages.py`, shared header/footer and links in `build.py`, charts in `charts.py`, then rebuild.

## Restricted content

`CBU_FIGURES_PUBLIC` in `build.py` is `False`: the CBU page shows a method-only write-up and the figures in
`_private/restricted-img/` are never copied into `site/`. Set it to `True` only once the CBU team approves
publishing (e.g. after the IEEE paper is out); the full write-up with all five figures is already built in.

## Deploy (GitHub Pages)

Push to `main`. `.github/workflows/pages.yml` runs `build.py` and publishes only `site/`.
One-time setup: repo Settings → Pages → Source: **GitHub Actions**.
